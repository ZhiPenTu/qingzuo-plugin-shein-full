# 1688 采集规则

1688 没有面向普通卖家的商品接口，所以采集只能走浏览器。插件拿到的是底座给的结构化快照，**不是 HTML**：没有 Cookie、没有隐藏字段、没有密码框。

## 一次采集的动作顺序

1. 校验链接：必须是 `https`，主机名为 `detail.1688.com`、`m.1688.com` 或 `www.1688.com`，且不含账号密码。
2. `browser.open` 在右侧并排面板打开页面，返回 `tabId`。
3. `browser.waitFor` 等 `h1` 出现，最多 15 秒；超时不报错，继续拍快照。
4. `browser.snapshot` 拿节点列表。
5. `ui/collect.mjs` 的 `parseProductSnapshot` 提取字段。
6. 命中「需人工处理」就停下，否则没有标题或价格也停下，成功则落成草稿。

## 快照长什么样

```json
{
  "url": "https://detail.1688.com/offer/...html",
  "title": "页面标题",
  "truncated": false,
  "nodes": [
    { "ref": "qz-4", "role": "heading", "name": "纯棉针织围巾…", "value": "", "visible": true,
      "rect": { "x": 24, "y": 180, "width": 720, "height": 32 } },
    { "ref": "qz-9", "role": "img", "name": "主图", "value": "", "visible": true,
      "rect": { "x": 24, "y": 240, "width": 1000, "height": 1000 },
      "url": "https://cbu01.alicdn.com/img/....png" }
  ]
}
```

解析时只用 `visible !== false` 的节点。`rect` 用来分行、排序和判断图片大小。

## 各字段怎么取

| 字段 | 规则 |
| --- | --- |
| 标题 | `heading` 里最长的非导航文本（至少 4 字）；没有则用页面标题去掉「-阿里巴巴」「批发网」等后缀 |
| 价格 | 所有节点里能识别 `¥12.50` 或纯数字的最低价；一个都没有时取 SKU 最低价 |
| 起批量 | 匹配「`N` 件起批」或「起订量 `N`」，同时保留单位 |
| 属性 | 按 `y` 坐标每 8 px 聚成一行；成对单元格取「左名右值」，单格取「键：值」；最多 40 条 |
| SKU | 先找同时含「颜色/规格」列和「单价/价格」列的表头行，再逐行读颜色、单价、库存；最多 60 行 |
| 图片 | `img` 节点且 URL 以 jpg/png/webp/avif 结尾、宽高均 ≥ 300 px；按去掉尺寸后缀的 URL 去重，按面积从大到小排序 |
| 主图 | 近正方形（两边之差不超过较长边的 18%）的图取前 5 张；一张都没有时取面积最大的一张 |
| 详情图 | 其余图片最多 20 张 |
| 类目路径 | 标题上方的链接文本，取最后 3 段 |

快照会同时给出 `table` / `row` 容器和它们的单元格。容器只是把子节点文字重复一遍，解析时会跳过容器角色，否则整张表格会被判成「未知行」而整表漏采。`<th>` 在无障碍树里是 `columnheader` / `rowheader`，而不是 `cell`，两种都要认。

## 什么情况会停下来等人工

以下文本命中任意一个，就判为「需人工处理」，插件只提示，不做任何绕过：

- 滑动验证、安全验证、验证码
- 请先登录、登录后查看
- 访问受限、页面不存在

另外，标题与价格**同时**没识别到时也会停下——这种情况通常是页面没加载完或结构已经改版，硬猜没有意义。表格、SKU、图片各自缺失时不会中断，只会记一条提醒，草稿里能看出来并补。

登录态按插件隔离分区持久保存：第一次在右侧面板里手动登录，之后通常不用重复登录。验证码需要每次人工完成。

## 页面改版怎么修

平台知识只存在于 `ui/collect.mjs`，底座不参与。

1. 用新结构录一份快照，存成 `tests/fixtures/1688-detail-snapshot.json` 同格式的文件。
2. 在 `tests/collect.test.mjs` 加一条断言，覆盖这次改版影响到的字段。
3. 改 `ui/collect.mjs`，直到新老快照都通过。
4. 跑 `npm test`，再跑一次端到端（端到端用的是本地伪造页面，不受 1688 改版影响，用来确认整条链路没断）。

不要把 1688 的表头、类目词、图片规则搬到 `qingzuo-desktop`，也不要为了采集往页面里注入脚本或模拟滚动对抗检测。

## 已知识别不到的情况

- 懒加载图片：采集时还没进入视口的图不在快照里。可以在右侧面板手动滚动后再点一次采集。
- 非表格型属性：例如以富文本段落描述的参数，可能整段被当成描述而漏掉。
- 阶梯价：只取最低档价格，不保留阶梯区间；需要时按最低价重算加价系数。
- SKU 独立图片：目前只按颜色文本区分 SKU，不绑定每个颜色的专属图。
- 包装规格、箱规、混批规则：不采集，需要运营在审核页手填。
